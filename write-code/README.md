# write-code

Universal coding-hygiene reminders for any code-writing task. Mirrors the existing code's style instead of imposing one. Covers stop-and-ask discipline, backend instrumentation, and comment hygiene.

## What this skill does

- Reads the file you're editing and nearby files first; mirrors the existing style. No smuggled refactors.
- Blocks fabrication of stubs or mocks when required context is missing; stops and asks instead.
- Ensures new backend I/O boundaries (clients, storage layers) get the project's monitoring/metrics decorator.
- Keeps comments to non-obvious *why* only; no narrating comments, no design-doc references in code.

## Trigger phrases

Any coding task: implementing a feature, fixing a bug, refactoring, adding tests, modifying existing code.

## Extending this skill

This skill grows with real cases. When a new recurring coding pattern or hygiene rule surfaces, add it here rather than keeping it as a one-off correction.
